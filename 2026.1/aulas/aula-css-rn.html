Do CSS Web ao React Native

O que muda quando saímos do navegador?

CSS Web vs React Native

No React Native, não existe CSS tradicional. Usamos objetos JavaScript.

CSS Web

.titulo {
  background-color: #2d8659;
  color: white;
  font-size: 20px;
  padding: 10px;
  border-radius: 8px;
}
→

React Native

titulo: {
  backgroundColor: '#2d8659',
  color: 'white',
  fontSize: 20,
  padding: 10,
  borderRadius: 8,
}

Principais Diferenças

🌐 CSS Web 📱 React Native
background-color backgroundColor camelCase
font-size: 20px fontSize: 20 sem px
Arquivo .css separado StyleSheet.create({}) JS obj
Seletores: .class, #id Aplica direto via style={} direto
:hover, :active Pressable + callbacks eventos
Layout padrão: block Layout padrão: flexbox (column) flex

💡

"Se você sabe CSS, já sabe 80% dos estilos do React Native."

A diferença é a sintaxe (camelCase, sem unidades) e a ausência de seletores e cascata.

StyleSheet

Três formas de aplicar estilos no React Native

1 Estilo Inline 

<Text style={{ color: 'red', fontSize: 20 }}>
  Texto vermelho
</Text>
⚠️ Funciona, mas não é recomendado para código extenso — cria novos objetos a cada render.

2 Objeto de Estilo 

const meuEstilo = {
  color: 'red',
  fontSize: 20,
};

<Text style={meuEstilo}>Texto vermelho</Text>
💭 Melhor que inline, mas sem validação de propriedades nem otimização interna.

3 StyleSheet.create ✅ 

import { StyleSheet } from 'react-native';

3 StyleSheet.create ✅ 

import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  titulo: {
    color: 'red',
    fontSize: 20,
    fontWeight: 'bold',
  },
});

3 StyleSheet.create ✅ 

import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  titulo: {
    color: 'red',
    fontSize: 20,
    fontWeight: 'bold',
  },
});

// Uso no componente:
<Text style={styles.titulo}>
  Texto vermelho e negrito
</Text>
✅ Recomendado! Valida propriedades em dev, otimiza performance e separa lógica de estilo.

🔀 Combinando Estilos

Use um array para combinar múltiplos estilos:

// Combinação simples
<Text style={[styles.texto, styles.negrito]}>
  Texto com dois estilos
</Text>

// Estilo condicional
<Text style={[styles.texto, ativo && styles.destaque]}>
  Muda de cor se ativo = true
</Text>
📌 O último estilo do array tem prioridade — sobrescreve os anteriores (como CSS specificity).

Flexbox no React Native

O sistema de layout padrão — todo View já é flex!

O que é Flexbox?

  • Sistema de layout unidimensional (linha ou coluna)
  • No React Native, todo componente já é flex por padrão
  • Direção padrão: column ↓ (diferente da web!)

🎯 O segredo: flex: 1 no container + flex: 1 no content = footer fica grudado no rodapé!

🏆 Desafio: Tela de Login

Crie uma tela de login com:

  • Título "Bem-vindo" centralizado
  • Dois TextInput (email e senha) com borda e padding
  • Um Pressable estilizado como botão
  • Tudo centralizado vertical e horizontalmente

🏆 Resposta: Tela de Login 

import React, { useState } from 'react';
import { SafeAreaView, View, Text, TextInput,
         Pressable, StyleSheet } from 'react-native';

export default function LoginScreen() {
  const [email, setEmail] = useState('');
  const [senha, setSenha] = useState('');
  return (
    <SafeAreaView style={s.container}>
      <View style={s.form}>
        <Text style={s.titulo}>Bem-vindo</Text>
        <TextInput style={s.input} placeholder="Email"
          value={email} onChangeText={setEmail} />
        <TextInput style={s.input} placeholder="Senha"
          value={senha} onChangeText={setSenha} secureTextEntry />
        <Pressable style={s.btn}
          onPress={() => alert('Login!')}>
          <Text style={s.btnTxt}>Entrar</Text>
        </Pressable>
      </View>
    </SafeAreaView>
  );
}
const s = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center',
    backgroundColor: '#f0f4f8' },
  form: { padding: 32 },
  titulo: { fontSize: 28, fontWeight: '700',
    textAlign: 'center', color: '#1e293b', marginBottom: 32 },
  input: { backgroundColor: '#fff', borderWidth: 1,
    borderColor: '#cbd5e1', borderRadius: 10,
    padding: 14, fontSize: 16, marginBottom: 16 },
  btn: { backgroundColor: '#0056b3', borderRadius: 10,
    padding: 16, alignItems: 'center', marginTop: 8 },
  btnTxt: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

🏆 Desafio: Grid 2×2 de Cores

Crie um grid 2×2 com 4 quadrados coloridos:

  • Cada quadrado ocupa metade da largura
  • Use flexDirection: 'row' para cada linha
  • Arredonde os cantos com borderRadius

🏆 Resposta: Grid 2×2 

import React from 'react';
import { SafeAreaView, View, StyleSheet } from 'react-native';

const cores = ['#ef4444','#3b82f6','#f59e0b','#10b981'];

export default function Grid() {
  return (
    <SafeAreaView style={s.container}>
      <View style={s.row}>
        <View style={[s.box, 
          { backgroundColor: cores[0] }]} />
        <View style={[s.box, 
          { backgroundColor: cores[1] }]} />
      </View>
      <View style={s.row}>
        <View style={[s.box, 
          { backgroundColor: cores[2] }]} />
        <View style={[s.box, 
          { backgroundColor: cores[3] }]} />
      </View>
    </SafeAreaView>
  );
}
const s = StyleSheet.create({
  container: { flex: 1, padding: 12 },
  row: { flex: 1, flexDirection: 'row', 
         gap: 12, marginBottom: 12 },
  box: { flex: 1, borderRadius: 16 },
});

Resumo da Aula

📝 React Native usa objetos JS, não CSS. Use StyleSheet.create
🔤 Propriedades em camelCase, sem unidades (px)
📦 Flexbox é o layout padrão — direção column
🎯 justifyContent = eixo principal · alignItems = eixo cruzado
✨ flex: 1 = "ocupe todo o espaço disponível"
