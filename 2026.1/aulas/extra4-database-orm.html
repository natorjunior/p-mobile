🔮 O que é ORM?

Object-Relational Mapping: técnica que mapeia objetos do código para tabelas do banco de dados, sem escrever SQL diretamente.

📱 Aplicação (JavaScript)
Trabalha com objetos e métodos
⬇️ ORM traduz automaticamente ⬇️
🔮 ORM (Sequelize)
Converte objetos ↔ SQL
⬇️ Gera SQL ⬇️
🗄️ Banco de Dados (SQLite)
Armazena os dados em tabelas

⚔️ SQL Puro vs ORM

INSERT INTO usuarios
  (nome, email, idade)
VALUES
  ('Maria', 'maria@email.com', 25);


SELECT * FROM usuarios
WHERE idade > 20

await Usuario.create({
  nome: 'Maria',
  email: 'maria@email.com',
  idade: 25

await Usuario.findAll({
  where: { idade: { [Op.gt]: 20 } },
  order: [['nome', 'ASC']]
});

🔄 CRUD com Sequelize

Create • Read • Update • Delete

➕ Create — Criar Registro

Inserindo um novo usuário


// Criar um usuário
const novoUsuario = await Usuario.create({
  nome: 'Maria Silva',
  email: 'maria@email.com',
  idade: 25
});

console.log(novoUsuario.id);  // 1 (gerado automaticamente)

➕ Create — Criar Vários

Inserindo múltiplos registros de uma vez


// Criar vários usuários de uma vez
const usuarios = await Usuario.bulkCreate([
  { nome: 'João Costa', email: 'joao@email.com', idade: 30 },
  { nome: 'Ana Souza', email: 'ana@email.com', idade: 22 },
  { nome: 'Pedro Lima', email: 'pedro@email.com', idade: 28 }
]);

console.log(usuarios.length);  // 3

🔍 Read — Buscar Todos

Equivalente a SELECT * FROM usuarios


// Buscar todos os usuários
const todos = await Usuario.findAll();

console.log(todos.length);

🔍 Read — Buscar por ID

Buscando um registro específico


// Buscar por chave primária (ID)
const usuario = await Usuario.findByPk(1);

console.log(usuario.nome);   // 'Maria Silva'
console.log(usuario.email);  // 'maria@email.com'

🔍 Read — Buscar com Filtro

Usando condições (WHERE)


const { Op } = require('sequelize');

// Buscar com condição
const jovens = await Usuario.findAll({
  where: {
    idade: { [Op.lt]: 30 }  // idade menor que 30
  }
});

🔍 Read — Buscar Um

Retorna apenas o primeiro resultado


// Buscar um único registro
const maria = await Usuario.findOne({
  where: { nome: 'Maria Silva' }
});

console.log(maria.email);  // 'maria@email.com'

✏️ Update — Atualizar Registro

Alterando dados existentes


// Buscar o usuário
const usuario = await Usuario.findByPk(1);

// Atualizar o campo
usuario.idade = 26;

// Salvar no banco
await usuario.save();

✏️ Update — Forma Direta

Atualizando com um único comando


// Atualizar diretamente

  { idade: 26 },               // novos valores
  { where: { id: 1 } }         // condição
);

🗑️ Delete — Forma Direta

Removendo com condição


// Remover diretamente

// Um usuário tem muitos posts
Usuario.hasMany(Post);

// Um post pertence a um usuário
Post.belongsTo(Usuario);

🛡️ Validações

Protegendo a integridade dos dados

🛡️ Validações no Model

Garantindo dados válidos


const Usuario = sequelize.define('Usuario', {
  nome: {
    type: DataTypes.STRING,
    allowNull: false,
    validate: {
      notEmpty: true,
      len: [2, 100]       // mínimo 2, máximo 100 caracteres
    }
  },
  email: {
    type: DataTypes.STRING,
    unique: true,
    validate: {
      isEmail: true        // valida formato de email
    }
  },
  idade: {
    type: DataTypes.INTEGER,
    validate: {
      min: 0,
      max: 150
    }
  }
});

🛡️ Tratando Erros

Capturando erros de validação


app.post('/usuarios', async (req, res) => {
  try {
    const usuario = await Usuario.create(req.body);
    res.status(201).json(usuario);
  } catch (erro) {
    if (erro.name === 'SequelizeValidationError') {
      const msgs = erro.errors.map(e => e.message);
      return res.status(400).json({ erros: msgs });
    }
    res.status(500).json({ erro: 'Erro interno' });
  }
});

🔎 Consultas Avançadas

Operadores e Filtros

🔎 Operadores de Comparação

Filtrando com precisão


const { Op } = require('sequelize');

// Maior que
const adultos = await Usuario.findAll({
  where: { idade: { [Op.gte]: 18 } }
});

// Entre valores
const faixa = await Usuario.findAll({
  where: { idade: { [Op.between]: [20, 30] } }
});

// Contém texto
const marias = await Usuario.findAll({
  where: { nome: { [Op.like]: '%Maria%' } }
});

🔎 Ordenação e Limite

Organizando os resultados


// Ordenar por nome (A-Z)
const ordenados = await Usuario.findAll({
  order: [['nome', 'ASC']]
});

// Limitar e paginar
const pagina = await Usuario.findAll({
  limit: 10,         // 10 por página
  offset: 20,        // pular os 20 primeiros
  order: [['createdAt', 'DESC']]
});

🔎 Contar e Agregar

Obtendo estatísticas


// Contar registros
const total = await Usuario.count();

// Contar com filtro
const totalJovens = await Usuario.count({
  where: { idade: { [Op.lt]: 30 } }
});

// Buscar + contar em uma chamada
const { count, rows } = await Usuario.findAndCountAll({
  where: { idade: { [Op.gte]: 18 } },
  limit: 10
});

Crie um Model Produto com: nome (string, obrigatório), preco (float), estoque (integer, padrão 0). Depois, escreva uma rota GET que retorne todos os produtos com estoque maior que zero, ordenados pelo preço.

✅ Resolução — Model


const Produto = sequelize.define('Produto', {
  nome: {
    type: DataTypes.STRING,
    allowNull: false
  },
  preco: {
    type: DataTypes.FLOAT
  },
  estoque: {
    type: DataTypes.INTEGER,
    defaultValue: 0
  }
});

✅ Resolução — Rota


app.get('/produtos', async (req, res) => {
  const produtos = await Produto.findAll({
    where: {
      estoque: { [Op.gt]: 0 }
    },
    order: [['preco', 'ASC']]
  });
  res.json(produtos);
});
Resumo: define (cria model) → findAll (busca) → where (filtra) → order (ordena).
