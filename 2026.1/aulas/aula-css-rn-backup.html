🌐 Do CSS Web ao React Native

O que muda quando saímos do navegador?

CSS Web vs React Native

No React Native, não existe CSS tradicional.

Em vez disso, usamos objetos JavaScript que imitam o CSS.

🌐 CSS Web

.titulo {
  background-color: darkgreen;
  color: white;
  font-size: 20px;
  padding: 10px;
}

📱 React Native

const styles = StyleSheet.create({
  titulo: {
    backgroundColor: 'darkgreen',
    color: 'white',
    fontSize: 20,
    padding: 10,
  }
});

⚠️ Principais Diferenças

CSS Web React Native
background-color backgroundColor (camelCase)
font-size: 20px fontSize: 20 (sem "px")
Arquivo .css separado StyleSheet.create({})
Seletores: .classe, #id, tag Sem seletores — aplica direto via style={}
Pseudo-classes: :hover, :active Não existe — usa eventos (onPress, Pressable)
Layout padrão: block Layout padrão: flexbox (column)

💡 Regra de Ouro

"Se você sabe CSS, já sabe 80% dos estilos do React Native."

A diferença é a sintaxe (camelCase, sem unidades) e a ausência de seletores e cascata.

Cada componente recebe seu estilo individualmente via style={}.






📝 StyleSheet

Três formas de aplicar estilos no React Native.

1️⃣ Estilo Inline

<Text style={{ color: 'red', fontSize: 20 }}>
  Texto vermelho
</Text>

⚠️ Funciona, mas não é recomendado para código extenso.

2️⃣ Objeto de Estilo

const meuEstilo = {
  color: 'red',
  fontSize: 20,
};

<Text style={meuEstilo}>
  Texto vermelho
</Text>

Melhor, mas ainda não tem validação nem otimização.

3️⃣ StyleSheet.create ✅

import { StyleSheet } from 'react-native';

3️⃣ StyleSheet.create ✅

import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  titulo: {
    color: 'red',
    fontSize: 20,
    fontWeight: 'bold',
  },
});

3️⃣ StyleSheet.create ✅

import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  titulo: {
    color: 'red',
    fontSize: 20,
    fontWeight: 'bold',
  },
});

// Uso no componente:
<Text style={styles.titulo}>
  Texto vermelho e negrito
</Text>

✅ Recomendado! Valida propriedades, otimiza performance e separa lógica de estilo.

🔀 Combinando Estilos

Use um array para combinar múltiplos estilos:

<Text style={[styles.texto, styles.negrito]}>
  Texto com dois estilos
</Text>

// Ou com estilo condicional:
<Text style={[styles.texto, ativo && styles.ativo]}>
  Texto condicional
</Text>

📌 O último estilo do array tem prioridade (sobrescreve).






🎯 Propriedades Essenciais

Texto, cores, bordas e espaçamento.

📝 Texto

const styles = StyleSheet.create({
  texto: {
    fontSize: 18,           // tamanho da fonte
    fontWeight: 'bold',     // peso: 'normal', 'bold', '100'-'900'
    fontStyle: 'italic',    // estilo: 'normal', 'italic'
    color: '#333',          // cor do texto
    textAlign: 'center',    // alinhamento: 'left', 'center', 'right'
    textDecorationLine: 'underline', // sublinhado
    letterSpacing: 2,       // espaço entre letras
    lineHeight: 28,         // altura da linha
  },
});

🎨 Cores

React Native aceita vários formatos de cor:

// Nome da cor
color: 'red'
color: 'dodgerblue'

// Hexadecimal
color: '#FF5733'
color: '#333'

// RGB / RGBA
color: 'rgb(255, 87, 51)'
color: 'rgba(0, 0, 0, 0.5)'  // com transparência

📦 Bordas e Arredondamento

const styles = StyleSheet.create({
  card: {
    borderWidth: 1,             // espessura da borda
    borderColor: '#ccc',        // cor da borda
    borderRadius: 10,           // arredondamento (todos os cantos)
    borderTopLeftRadius: 20,    // canto específico

    // Sombra (iOS)
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.25,
    shadowRadius: 3.84,

    // Sombra (Android)
    elevation: 5,
  },
});

📐 Margin vs Padding

← margin →

← padding →

Conteúdo

← padding →

← margin →

// margin = espaço FORA do componente
// padding = espaço DENTRO do componente
{
  margin: 10,          // todos os lados
  marginTop: 20,       // só em cima
  marginHorizontal: 15,// esquerda + direita
  padding: 10,
  paddingVertical: 5,  // cima + baixo
}

📦 Flexbox no React Native

O sistema de layout padrão.

O que é Flexbox?

  • Sistema de layout unidimensional (linha ou coluna).
  • No React Native, todo componente já é flex por padrão.
  • Direção padrão: column (de cima para baixo).

🌐 CSS Web

Padrão: row (→)

📱 React Native

Padrão: column (↓)

flexDirection

Define a direção dos filhos:

// Vertical (padrão)
flexDirection: 'column'     // ↓

// Horizontal
flexDirection: 'row'        // →

// Invertidos
flexDirection: 'column-reverse' // ↑
flexDirection: 'row-reverse'    // ←

flexDirection — Visual

flex — Proporção

Controla quanto espaço cada filho ocupa:

flex: 1
flex: 2
flex: 1
<View style={{ flexDirection: 'row' }}>
  <View style={{ flex: 1, backgroundColor: 'red' }} />
  <View style={{ flex: 2, backgroundColor: 'blue' }} />
  <View style={{ flex: 1, backgroundColor: 'green' }} />
</View>

📌 flex: 1 em um componente pai = "ocupe todo o espaço disponível".

🎯 Como Centralizar?

A pergunta mais frequente do CSS também se aplica aqui:

const styles = StyleSheet.create({
  centralizado: {
    flex: 1,
    justifyContent: 'center',  // centraliza no eixo principal
    alignItems: 'center',      // centraliza no eixo cruzado
  },
});

📌 flex: 1 + justifyContent: 'center' + alignItems: 'center' = centralização perfeita! ✨

Crie um componente ProfileCard que exiba:

Atividade 2: Layout com Flexbox

Crie uma tela com o seguinte layout:

  • Header fixo no topo (fundo azul, texto branco centralizado)
  • Conteúdo que ocupa todo o espaço restante (centralizado)
  • Footer fixo no rodapé (fundo cinza escuro)

💡 Use flex: 1 no container e no conteúdo. Header e Footer são fixos.

Atividade 2: Resposta

import React from 'react';
import { SafeAreaView, View, Text, StyleSheet } from 'react-native';

export default function Layout() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.headerText}>Meu App</Text>
      </View>
      <View style={styles.content}>
        <Text style={{ fontSize: 18 }}>Bem-vindo!</Text>
      </View>
      <View style={styles.footer}>
        <Text style={styles.footerText}>© 2026</Text>
      </View>
    </SafeAreaView>
  );
}
const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  header: { backgroundColor: '#0056b3', padding: 15, alignItems: 'center' },
  headerText: { color: '#fff', fontSize: 20, fontWeight: 'bold' },
  content: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  footer: { backgroundColor: '#333', padding: 10, alignItems: 'center' },

🏆 Desafios

Combine estilos e layout!

Desafio 1: Tela de Login

Crie uma tela de login estilizada com:

  • Um título "Bem-vindo" centralizado no topo
  • Dois campos de entrada (TextInput) com borda e padding
  • Um botão (Button ou Pressable) estilizado
  • Tudo centralizado vertical e horizontalmente
  • Use StyleSheet.create para todos os estilos

Desafio 1: Resposta

import React, { useState } from 'react';
import { SafeAreaView, View, Text, TextInput, Button, StyleSheet } from 'react-native';

export default function LoginScreen() {
  const [email, setEmail] = useState('');
  const [senha, setSenha] = useState('');

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.form}>
        <Text style={styles.titulo}>Bem-vindo</Text>
        <TextInput style={styles.input} placeholder="Email"
          value={email} onChangeText={setEmail} />
        <TextInput style={styles.input} placeholder="Senha"
          value={senha} onChangeText={setSenha} secureTextEntry />
        <Button title="Entrar" onPress={() => alert('Login!')} />
      </View>
    </SafeAreaView>
  );
}
const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', backgroundColor: '#f0f0f0' },
  form: { padding: 30 },
  titulo: { fontSize: 28, fontWeight: 'bold', textAlign: 'center',
    color: '#333', marginBottom: 30 },
  input: { backgroundColor: '#fff', borderWidth: 1, borderColor: '#ccc',
    borderRadius: 8, padding: 12, fontSize: 16, marginBottom: 15 },
});

Desafio 2: Grid de Cores

Crie um grid 2×2 com 4 quadrados coloridos usando Flexbox:

  • Cada quadrado deve ocupar metade da largura
  • Use flexDirection: 'row' para cada linha
  • Arredonde os cantos com borderRadius

Desafio 2: Resposta

import React from 'react';
import { SafeAreaView, View, StyleSheet } from 'react-native';

const cores = ['#e74c3c', '#3498db', '#f1c40f', '#2ecc71'];

export default function Grid() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.row}>
        <View style={[styles.box, { backgroundColor: cores[0] }]} />
        <View style={[styles.box, { backgroundColor: cores[1] }]} />
      </View>
      <View style={styles.row}>
        <View style={[styles.box, { backgroundColor: cores[2] }]} />
        <View style={[styles.box, { backgroundColor: cores[3] }]} />
      </View>
    </SafeAreaView>
  );
}
const styles = StyleSheet.create({
  container: { flex: 1, padding: 10 },
  row: { flex: 1, flexDirection: 'row', gap: 10, marginBottom: 10 },
  box: { flex: 1, borderRadius: 12 },
});

📋 Resumo da Aula

  • React Native usa objetos JS em vez de CSS tradicional
  • StyleSheet.create é a forma recomendada
  • Propriedades em camelCase, sem unidades (px)
  • Flexbox é o sistema de layout padrão (direção column)
  • justifyContent → eixo principal / alignItems → eixo cruzado
  • flex: 1 = "ocupe todo o espaço disponível"
